## 🧠 What is Homework AI?

Homework AI is a **lightweight yet powerful Chrome extension** engineered for one goal:

> 📚 **Provide instant, contextual answers to academic questions directly in your browser — without breaking flow.**

No tab switching.
No copy-pasting.
Just drop the question → Get the explanation.

It’s the **perfect learning companion** for students and professionals who value time, clarity, and focus.


<br />

## 🔥 Features That Make It a Game-Changer

👉 **On-Page Popup Interface**
Effortlessly overlays on your current screen – ideal for seamless use during online learning platforms.

👉 **High-Speed OCR**
Upload or highlight image-based queries and receive textual answers within seconds.

👉 **Drag & Drop Image Upload**
Interactively feed visual questions — get intelligent responses on the fly.

👉 **Smart Side Panel**
Switch between AI models, scan new questions, and choose short or detailed explanations.

👉 **Answer + Insight Mode**
Go beyond answers — gain conceptual clarity and reasoning with every response.

👉 **Privacy-First**
All operations run in-browser. No external data storage or logging.


<br />

## 💡 Use Cases

## ⚙️ Tech Stack

* `Vanilla JavaScript` (no third-party frameworks)
* `HTML/CSS` (minimalist UI)
* `Tesseract.js` OCR Engine for image parsing
* `OpenAI API and Gemini` (GPT-3.5/Gemini for contextual reasoning)
* Chrome Extension APIs

<br />

## 📦 Installation Guide

1. Clone or download this repository
2. Open Chrome and navigate to `chrome://extensions/`
3. Enable **Developer Mode**
4. Click **Load Unpacked** → Select the `HomeworkAI` folder
5. Pin the extension → Start using instantly 🎉
